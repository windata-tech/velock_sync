# iOS 上架前真机清单（格间 2.0.7 + Velock Sync 1.0）

只覆盖 iOS。macOS / Windows / Android 本轮不提交。
自动化部分（两仓库全量测试、Release 无签名编译、隐私清单）已完成；下面是必须人工在真机上确认的项。

## 提交顺序

1. 先提交 **格间 2.0.7**，审核通过并上架。
2. 再提交 **Velock Sync 1.0**。Sync 需要 2.0.7 的能力握手，遇到 2.0.6 只会提示更新格间。
3. Sync 上架后，如需要再给格间的更新说明 / FAQ 补商店链接。

## A. 格间 2.0.6 → 2.0.7 覆盖升级（一台有真实数据的设备）

- [ ] 从商店版 2.0.6 直接覆盖安装 2.0.7（不删 App）。
- [ ] 主密码解锁、Face ID / Touch ID 解锁都正常。
- [ ] 账号、信用卡、备注能打开详情；文件能打开正文；相册能看原图。
- [ ] 旧恢复卡 / 恢复码在设置中仍显示为可用。
- [ ] 删除一个文件和一张照片 → 出现在「最近删除」→ 恢复一次、永久删除一次都正常。
- [ ] 切换到英文和另一种语言（如日语）看删除确认框和「最近删除」，没有中文残留。
- [ ] 自动填充（密码 AutoFill 扩展）在 Safari 里还能填。
- [ ] 分享扩展：从「照片」分享一张图到格间能导入。

## B. 两个 App 的完整备份与恢复（两台设备，Release 包，TestFlight 即可）

设备 1（源）：
- [ ] 格间 设置 › 云备份 打开「允许 Sync 连接」，点「前往 Sync」能跳到 Sync。
- [ ] Sync 选择 WebDAV（NAS 用 `USB_HDD_8T` 下有写权限的目录），建立格间备份，格间弹出批准页 → 允许。
- [ ] 「立即备份」完成，记录显示上传对象数 > 0。
- [ ] 抄下新版纸质恢复卡（名称、密钥、密码、校验码）。
- [ ] 格间里新增 1 个账号、1 个文件后，再点一次备份，不重启格间就能传上去。

设备 2（新设备，全新安装两个 App）：
- [ ] 格间用纸质恢复卡恢复原账号（Sync 取回云端加密恢复文件）。
- [ ] Sync 连接同一个目录，格间批准，恢复完成。
- [ ] 逐项打开核对：账号详情、信用卡详情、备注正文、文件正文、照片原图，与设备 1 一致。
- [ ] 设备 1 再新增一条内容并备份 → 设备 2 同步后能看到。

## C. 文件同步（Sync，普通明文镜像）

- [ ] 添加同步位置：本机文件夹 ⟷ NAS 目录，双向。
- [ ] 本机新建/修改/删除文件，另一侧对应变化；删除较多文件时出现删除确认表。
- [ ] 两边同时改同一个文件 → 出现「本机冲突」副本，两份都在。

## D. 审核员视角（只装一个 App 时）

- [ ] 只装格间、不装 Sync：设置 › 云备份 的「前往 Sync」弹出「未能打开 Sync…」而不是没反应。
- [ ] 只装 Sync、不装格间：格间 tab 给出清楚的“需要安装格间”说明，文件同步 tab 可以独立使用。
- [ ] Sync 审核说明（`docs/release/app-review-notes.md`）里的步骤按一遍能走通。

## E. 提交前

- [ ] 两个仓库从 `main` 打包；格间版本 2.0.7 (12)、Sync 1.0.0 (1)。
- [ ] Xcode Archive 上传后 App Store Connect 没有隐私清单（ITMS-91053）警告。
- [ ] App Store Connect 隐私问卷：两个 App 都是「不收集数据」。
- [ ] 更新说明里注明：旧版 iOS 可能已损坏少量加密文件，新版不再产生，但无法修复已损坏的文件。
