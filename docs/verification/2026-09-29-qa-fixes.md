# 2026-09-29 双模拟器 QA 问题修复

来源：同日两台 Debug 模拟器（Sync + 格间）数据同步 QA 的 19 条发现（截图/视频在
`ui_test_results/release-qa/delivery-debug-simulator-20260929/`，01/04/04b 与 01-recovery-card 含测试恢复卡，禁止外传）。
报告中没有第 5 条；其余 18 条全部修复。

## Sync（本仓库）

| # | 问题 | 修复 |
|---|---|---|
| 19 | WebDAV 密码错误(401)后格间备份只能进管理页，无法改密码也无法重试 | 新增 `BackupAction.fixConnection`，401/unauthorized 主操作「修改连接」直达连接编辑（`backup_connection_fix.dart`，`returnTo=pop` 返回原页）；保存后**另行确认**「重试备份」，保存本身不启动备份；详情页对其他可处理失败始终保留重试 |
| 7 | 恢复出的 profile 后台关闭，卡在「等待格间恢复」 | `local.velock_snapshot_application_required` 提供「检查恢复进度」（`backup-check-restore`，调用 runner）；首页从格间回前台时对这类 profile 自动检查一次 |
| 17 | 连接被拒绝时报「没有网络连接」 | `connectionError`/`SocketException` 改为 `network.unreachable`（检查网络、地址端口与服务器是否运行）；旧 `network.offline` 记录仍可正确显示 |
| 18 | 格间失败弹窗写「同步失败」；401 提示「重新授权」 | 格间域用「备份失败」；401 文案改为核对用户名密码（云盘重新授权） |
| 9 | 回前台自动同步完成后首页不更新 | 前台自动运行结束后 bump `profilesRevisionProvider` 并刷新明文位置 |
| 2 | 默认连接名「新建连接」像按钮 | 未填名称时按地址/服务生成名称 |
| 3 | 地址错误未提示 `http://` | 「请输入以 http:// 或 https:// 开头的完整地址，例如 https://nas.example.com」 |
| 4 | 从目录选择器回到「从云端恢复」页无返回键 | 恢复引导页头始终有 `AppBackButton`（不能 pop 则回首页） |
| 10 | 文件同步远端目录选择器写「备份」 | `BackupFolderPicker(forSync: true)` 用「同步」措辞 |
| 11 | 选择器显示地址缺端口 | `RemoteObjectStoreFactory.webDavDisplayAddress` 含端口 |
| 12 | 「同一条文件」 | 改「同一个文件」 |
| 13 | 保留两份时本机冲突副本要下一轮才上传 | 同一次运行内上传冲突副本，下一轮无多余传输 |
| 14 | 删除确认写「两边已一致」并称删本地 | 按实际待删方向与状态描述（`held_deletion_wording_test.dart`） |
| 15 | 「冲突 1」标记无法清除 | 冲突记录弹窗可「清除记录」，只删记录不动文件 |
| 16 | 文件同步可选中格间备份目录 | 除本机已配置备份外，按内容识别：路径或直接子目录含 `velock-sync` 即拒绝（读不到子目录交给可写预检） |

验证：`flutter analyze` No issues；全量 **1303** 项测试通过。

## 格间（`../velock_codex`）
