# 教程覆盖范围纠正：文件、相册优先

## 原因与旧证据边界

用户指出文件、相册才是重点，普通账号、信用卡、日记须分别展示。旧录制器固定 `E2E_REQUIRED_KINDS=password`，源 seed 在保存密码后提前返回；恢复只打开 e2e-user。这是覆盖范围遗漏，不能拿旧原片证明全类型同步正常，也不能仅据此断言同步产品存在丢文件 bug。

## 本轮变更

- 默认 host 门禁固定 file/media/password/card/note/document，禁止降为 password 子集。全内容模式必须保留已准备六类内容的源设备；先只读校验真实数据库/加密文件，再允许启动或重置模拟器。
- UI 原片路径改成先文件与相册，再普通账号、信用卡、备注；源设备和恢复设备均生成五类 UI 覆盖报告。document 为额外 host 验证，未宣称手机展示了文档正文。
- 信用卡有独立 `E2E_SEED_CREDIT_CARD=1` seed 参数，用合成 Visa 卡示例；既有通用银行卡回归不改名。
- 新图片 fixture 是清晰可见的 960×640 彩色合成图，替换1像素样例，不使用用户照片。
- file/media 目录不再算有内容；要求非空加密载荷及媒体元数据。源副本比较实体 revision、恢复业务字段、文件/相册密文字节大小/hash、父子关系；凭证/文档会重加密，不错误要求密文hash相同，也不把host元数据比较当作解密正文验证。
- Companion 增加按文件名定位的真实文件/相册语义，以及只在原图解码完成后的特定media id成功语义；缩略图、失败占位图、旧图异步完成不会冒充目标原图就绪。
- 中英文手册、录制操作手册、AGENTS 项目记忆同步纠正。
