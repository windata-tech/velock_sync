# 行图标补齐（2026-09-27）

## 用户反馈

管理 tab 截图，箭头指着「重新连接格间」：**「这里差一个图标」**。
该行正上方是带云图标的「更换保存位置」，自己却没有 leading。

## 排查

同一张卡片里缺图标的不止这一行。用脚本扫了详情页/设置页/明文页的 `AdaptiveListTile`，
凡是**同卡其它行都有 leading** 的：

- `sync_profile_detail.dart`「重新连接格间」（管理 tab，云图标下面一行）
- `sync_profile_detail.dart`「查看等待传输的内容」（概览卡，条件渲染，只有存在等待传输时出现）

不在范围内（整张卡只有一行，卡内自洽，未改）：概览页的「暂停备份」「详细记录与诊断」；
设置页「版本与许可」整段（协议版本/应用版本/关于与开源许可）与「默认蜂窝网络传输上限」；
后台策略的三个开关行（`AdaptiveSwitchListTile` 全仓库都没有 leading，是既定形态）。

## 改动

- 「重新连接格间」→ `leading: const Icon(CupertinoIcons.link)`。link 是本 App 既有的“连接”词汇
  （`new_connection.dart` 的新增连接行、`connection.dart` 的连接详情页头同款）。
- 「查看等待传输的内容」→ `leading: const Icon(CupertinoIcons.tray_arrow_down)`，
  与 `_PendingTab` 空状态同一个图标。
- 两处都只加 leading，不动文案、点击行为、条件渲染与禁用逻辑。
