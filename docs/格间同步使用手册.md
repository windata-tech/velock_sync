# 格间同步使用手册

适用：当前 iOS 版格间与 Velock Sync；以下以 WebDAV 为例。界面名称随版本可能略有变化。

> 配套教程面向全新、隔离且从未同步的演示空间，不是旧空间迁移到空远端的教程。实际配置请使用自己的服务器、账号和同步目录；不要照抄视频中的本机地址或 HTTP 选项。演示中的 `localhost` / `127.0.0.1` 仅用于录制电脑上的本地模拟器测试，不能作为另一台实体设备可访问的服务器地址；真实使用须配置两台设备均可访问的 HTTPS 服务。

## 先了解两个 App 的分工

- **格间**：创建、查看和编辑你的内容，负责内容的加密与解密。
- **Velock Sync**：经你批准后，将格间的加密数据传到远端，并下载其他设备的数据。

第一次使用，需要先在格间允许配对，再让 Velock Sync 连接远端。换手机时，需要先恢复原来的格间账号，再配置同步。

## 开始前准备

1. 在设备上安装格间与 Velock Sync。
2. 准备可用的 WebDAV 服务，以及服务商提供的地址、端口、账号、密码和目录。
3. 确认账号对同步目录有读写权限，建议为格间准备单独目录。
4. 使用 HTTPS。不要照抄演示视频中的本机地址或测试账号。
5. 妥善保管格间恢复卡。**恢复卡和二维码包含敏感恢复信息，不要发到群聊、论坛或公开视频中。**

## 第一部分：首次开启同步

### 0. 先核对源设备的内容

首次配置前，先在格间正常创建或导入不敏感的样例，确认保存后能够打开。教程要求在源设备分别展示以下五类，再进行首次配对和上传：

- **文件**：打开 `velock-sync-e2e-proof.txt`，看到正文 `VELOCK SYNC REAL DATA E2E`。
- **相册**：打开合成演示照片的原图，不以缩略图代替。导入后的文件名可能由系统重命名。
- **普通账号**：打开 `E2E Password`，确认账号 `e2e-user` 可读；密码保持掩码。
- **信用卡**：单独打开 `E2E Credit Card` 并核对合成测试卡信息，不使用真实卡信息。
- **日记/备注**：本教程用备注作为样例；打开 `E2E note content`，确认正文包含 `恢复校验正文`，不将其冒称独立日记功能的验收。

这些名称只是教程样例，实际使用请核对自己的对应内容。额外的文档校验与上述五类手机界面展示不同，见文末说明。

### 1. 在格间允许配对

1. 打开格间，进入并解锁需要同步的空间。
2. 打开 **设置 → 实验性 - 数据同步**。
3. 找到 **允许新的配对**，打开开关，并在提示中点击 **启用**。
4. 如果出现换机恢复卡页面，点击 **保存恢复卡到相册**，按提示完成保存。
5. 返回连接设置，确认已经启用。如果此前漏存，可在该页面选择 **重新生成换机恢复卡**。

**重要：启用同步后生成的换机恢复卡不同于最初注册时的普通恢复卡。请保留用于当前同步空间的换机恢复卡，并另做安全备份。不要只把唯一副本留在这台手机上。**

### 2. 在 Velock Sync 添加远端连接

1. 打开 Velock Sync，进入底部 **连接**。
2. 点击 **添加远端连接** 或 **新建连接**。
3. 点击 **选择远端协议**，选择 **WebDAV**。
4. 根据服务商提供的信息填写服务器地址、端口、用户名、密码及子路径，保留 HTTPS。
5. 点击 **保存**。如果连接失败，先核对网络、地址、凭据和目录权限。

这里填写的是 **WebDAV 服务密码**，不是格间空间的解锁密码。

### 3. 将格间与 Velock Sync 配对

1. 进入 Velock Sync 底部 **同步**。
2. 点击 **开启格间备份 → 开始连接格间 → 开始配对**。
3. 系统询问是否打开格间时，点击 **打开**。
4. 在格间中解锁空间，核对配对请求来自 **Velock Sync**。
5. 点击请求上的 **批准**，并确认批准。
6. 返回 Velock Sync，按提示选择刚才添加的远端连接。
   - 只有一个可用连接时，可能直接进入确认页。
   - 尚未添加连接时，可点击 **去创建连接**，完成后继续。
7. 核对空间与远端目标，点击 **确认并创建**。
8. 等待首次同步结果；出现失败提示时，先处理错误，不要把“配置已创建”当成“数据已备份”。

### 4. 确认可以正常使用

1. 在同步列表中打开对应的格间配置，查看同步结果。
2. 回到格间，确认原有内容仍可正常打开。
3. 第一次正式使用，建议用不敏感样例，在另一台设备按文末清单逐类完成下载和打开验证；一条账号成功不能代表文件、照片、卡片和备注都成功。

## 第二部分：日常同步

1. 在格间完成内容编辑，并确认已保存。
2. 打开 Velock Sync，进入 **同步 → 对应的格间配置**。
3. 点击 **立即同步**，等待完成。
4. 在另一台已配对设备上，同样点击 **立即同步**。
5. 回到另一台设备的格间，解锁空间并查看内容；页面提供 **打开格间** 时可以直接点击。

“没有需要同步的新数据”表示本轮没有待传输的新数据。不要仅凭这个提示判断另一台设备的内容已经打开成功，仍应回到格间核对。

## 第三部分：在另一台设备恢复

### 1. 先恢复原来的格间账号

1. 在新设备安装格间与 Velock Sync。
2. 安全地准备原空间在启用同步后保存的换机恢复卡。
3. 打开格间，点击 **恢复一个账号 → 从二维码恢复**。
4. 使用页面提供的扫码方式，或点击 **从相册** 选择恢复卡。
5. 核对恢复信息，按页面要求完成设置，点击 **恢复账号**。
6. 如设备尚未配置 Face ID 等生物识别，可先不启用相应快捷解锁选项。
7. 进入恢复的空间。**不要改成“创建新空间”来替代恢复原账号。**

恢复账号和下载全部业务数据是两个步骤；刚进入空间时内容未齐全，不代表恢复卡失效。

### 2. 在新设备重新配对与下载

1. 在恢复后的格间空间打开 **设置 → 实验性 - 数据同步**，按提示允许配对。
2. 在新设备的 Velock Sync 添加与旧设备相同的 WebDAV 服务和同步目录。
3. 按第一部分的步骤开始配对，并在格间批准本次请求。
4. 完成配置并等待同步；必要时进入配置点击 **立即同步**。如果提示 **请打开格间并解锁以完成恢复**，按提示回到格间。
5. 返回格间并解锁，等待导入完成，再依次打开文件正文、照片原图、普通账号详情、信用卡详情、备注正文，和源设备逐项核对。额外文档仅按文末的 host 校验范围说明，不视为手机已展示文档正文。
6. 若旧设备出现 **批准新设备加入？**，核对设备确实属于自己后再批准；不要批准来源不明的请求。

**确认新设备的数据可以正常打开、恢复卡已安全保存之前，不要清空旧设备或删除远端目录。**

## 常见问题

| 现象 | 先检查什么 |
|---|---|
| 找不到可配对的格间 | 格间是否已安装、空间是否已解锁、是否已允许新的配对 |
| 配对一直等待 | 是否已到格间批准请求，以及是否已返回 Velock Sync |
| WebDAV 认证失败 | 服务账号和密码是否正确；不要填成格间解锁密码 |
| 目录不存在或无权限 | WebDAV 路径是否正确，账号是否有读写权限 |
| 同步完成但格间尚未显示内容 | 返回格间，解锁原空间，等待导入；确认没有进入另一个新建空间 |
| 提示远端历史不完整 | 保留旧设备和原远端，核对是否选错目录或遗漏历史备份；不要清空历史、跳过保护或改用空目录重试。此教程不提供旧空间自动全量迁移方案 |
| 提示远端不支持安全写入 | 当前服务的写入能力可能不兼容，联系服务管理员；不要删除已有数据或跳过保护 |

## 配套教程

- **视频 1 的验收范围：首次配置**——源设备实际打开上述五类内容 → 格间允许配对 → 添加 WebDAV → 批准配对 → 等待首次同步完成并查看结果。
- **视频 2 的验收范围：另一台设备恢复**——导入换机恢复卡 → 配对原空间 → 同步 → 先打开文件正文和照片原图，再分别打开账号、信用卡、备注详情。

录制要求只使用隔离的演示空间与演示内容，保留原始连续画面，不剪辑、不变速、不配音、不添加字幕；任何演示恢复卡不得用于保存真实数据。这里描述的是教程目标与验收要求，不代表新版视频已经录制或通过验收。

## 恢复后逐类检查（不能只检查账号）

请先保留原设备，优先在新设备检查：

- **文件**：打开实际文件查看正文，核对文件名、大小和文件夹位置；只有目录或文件名不代表内容恢复完成。
- **相册**：打开照片原图查看，不只看缩略图或相册数量；核对照片内容与相关信息。
- **普通账号**：打开账号详情，确认恢复的是对应账号。
- **信用卡**：单独打开卡片详情，核对卡片信息，不能用普通账号恢复成功代替。
- **日记/备注**：打开正文，确认完整内容，而不只是列表中的标题和摘要。

上述内容全部确认后，再决定是否停用原设备。此前基础配置演示只展示过一条账号，不应将其作为其他类型已恢复的证明。

## 额外文档校验与恢复边界

教程还要求在录制电脑端（host）检查第六类 **document 文档**：源设备与恢复设备均有非空加密文档，且对应实体的修订版本与恢复元数据一致。这是额外的持久化校验，**不是手机界面打开文档正文的证明，也不等于已验证解密后的正文**；不要把文档与备注混为一类。普通用户无需运行测试脚本，但不能把此项 host 结果理解为所有文档均已可读。

**已经同步过的旧空间不要直接改接空远端，并把“同步完成”当作完整备份。** 本教程的全新演示空间在首次配置前不得有已发布历史；恢复设备必须连接同一份完整远端。进度检查点不包含完整业务内容，恢复卡也不能替代远端业务备份。发现远端历史缺失时，保留原设备与完整旧备份并处理缺失问题；本教程不宣称旧空间自动全量迁移或补传已修复。
